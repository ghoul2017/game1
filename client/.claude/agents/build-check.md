# build-check

在对话结束前（或代码修改完成后）自动检查项目编译是否通过。

## 触发条件

用户代码修改完成后自动运行。

## 执行步骤

1. 运行编译命令：
   ```bash
   cd E:/worku/game1/client && dotnet build Assembly-CSharp.csproj 2>&1
   ```
2. 检查输出是否包含 `error` 关键字
3. 如果有错误，读取错误信息，定位到具体文件和行号，自动修复后重新编译
4. 如果反复修复失败（超过 3 次），向用户报告剩余错误，等待用户指示
5. 编译通过后简要报告结果

## 注意事项

- 修复编译错误时只改必要的最小范围，不做额外重构
- 如果是缺失 using 引用，直接补上
- 如果是类型找不到，先确认命名空间和程序集引用
