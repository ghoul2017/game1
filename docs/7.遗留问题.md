# 遗留问题

## [待解决] 客户端 CSV 路径硬编码为开发环境相对路径

`GameEntry.Start()` 中 `ConfigManager.LoadAll()` 使用 `Application.dataPath + "/../../server/Data/Tables"`，仅 Unity Editor 开发环境可用。

**解决方向**：正式构建时改用 `Application.streamingAssetsPath + "/Tables"`，将 CSV 复制到 `client/Assets/StreamingAssets/Tables/`。

---

## [待解决] 删除文件后 Unity csproj 未自动刷新

删除 `.cs` 文件后 `Assembly-CSharp.csproj` 仍引用已删除文件，`dotnet build` 报 CS2001。需在 Unity Editor 中 Assets → Refresh 重新生成 csproj。

**解决方向**：每次删除文件后提醒执行 Unity 刷新，或考虑 hook 自动化。

---

## [待解决] Monster AI 已知局限

1. **单目标仇恨**：AI 只追踪一个目标，`ThreatMap` 未接入，无法实现仇恨转移
2. **巡逻无路径**：`PatrolTarget` 为随机点，无固定巡逻路线
3. **攻击后回 Idle**：攻击完立即重置状态而非持续攻击，行为略显机械
4. **无脱战回血**：怪物脱离战斗后不会回血，下次被攻击时仍是残血

---

## [待解决] 安全：密码明文存储

User.Password 直接存储和比对，无加密。适合内网测试环境，但正式环境需改为哈希+盐。

---

## [待解决] 数据安全：无下线保存定时器

PlayerEntity 各 Component 仅在下线时保存，服务端崩溃可能丢失数据。需增加定时保存机制。

---

## [待解决] 物品过期未清理

BagItem 有 ExpireTime 字段、RoleMail 有 ExpireTime 字段，但都无定时清理逻辑，过期数据会持续堆积。

---
