## 1. 环境准备

### 1.1 启动服务端

```bash
cd server && dotnet run
```

- 预期：控制台输出 `TcpServer listening on 0.0.0.0:9000`
- 日志文件：`server/log/game.log`（普通日志）、`server/log/error.log`（错误日志）

### 1.2 启动客户端

- Unity Editor 打开 `client/` 目录，点击 Play
- 预期：显示 LoadingPanel → 自动跳转到 LoginPanel

### 1.3 查看日志的方式

| 来源 | 位置 |
|------|------|
| 服务端控制台 | 运行 dotnet run 的终端窗口 |
| 服务端日志文件 | `server/log/game.log`、`server/log/error.log` |
| Unity Editor 日志 | Console 面板（Window → General → Console） |
| Unity Player.log | `%LOCALAPPDATA%\Unity\Player.log` |

## 2. 登录与账号模块

### T2.1 正常登录

| 项目 | 内容 |
|------|------|
| 前置条件 | 服务端已启动，客户端在 LoginPanel |
| 测试步骤 | 1. 输入账号（任意非空字符串）<br>2. 输入密码（任意非空字符串）<br>3. 点击"登录"按钮 |
| 预期结果 | 登录成功，跳转到 RoleSelectPanel；服务端日志显示 `[LoginHandler] 登录成功` |
| 注意事项 | 首次登录会自动注册账号 |

### T2.2 空账号/密码登录

| 项目 | 内容 |
|------|------|
| 测试步骤 | 账号或密码留空，点击登录 |
| 预期结果 | 客户端提示"请输入账号和密码"或服务端返回错误码 |

### T2.3 记住密码

| 项目 | 内容 |
|------|------|
| 测试步骤 | 1. 勾选"记住密码"<br>2. 登录成功<br>3. 退出游戏重新打开 |
| 预期结果 | 账号密码自动填充，Toggle 显示勾选状态 |

### T2.4 重复登录（顶号）

| 项目 | 内容 |
|------|------|
| 测试步骤 | 1. 客户端A用账号 test1 登录<br>2. 客户端B用同一账号 test1 登录 |
| 预期结果 | 客户端A收到 KickNtf 被踢下线；客户端B正常登录 |
| 日志验证 | 服务端日志显示 `SessionManager: 顶号` |

### T2.5 断线重连

| 项目 | 内容 |
|------|------|
| 前置条件 | 已登录并进入游戏场景 |
| 测试步骤 | 1. 断开网络（关闭WiFi或拔网线）<br>2. 等待几秒后恢复网络 |
| 预期结果 | 客户端自动尝试重连（最多5次，指数退避）；重连成功后恢复游戏状态 |
| 日志验证 | 客户端 Console 显示 `[NetClient] Reconnecting...`；成功后显示 `Reconnect OK` |
