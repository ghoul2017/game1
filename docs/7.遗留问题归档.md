# 遗留问题归档

## [已解决] 客户端 CSV 路径硬编码为开发环境相对路径

`GameEntry.Start()` 原先直接使用 `Application.dataPath + "/../../server/Data/Tables"`，正式构建无法读取服务端目录。

**处理结果**：客户端配置加载改为 Editor 下优先读取 `server/Data/Tables`，目录不存在或正式构建时读取 `Application.streamingAssetsPath + "/Tables"`；当前 CSV 已同步到 `client/Assets/StreamingAssets/Tables/` 并补齐 `.meta`。

---

## [已解决] 删除文件后 Unity csproj 未自动刷新

删除 `.cs` 文件后 Unity 生成的 `Assembly-CSharp.csproj` 可能仍引用旧路径，导致 `dotnet build` 报 CS2001。

**处理结果**：新增 `scripts/check-all`，在 Unity csproj 缺失时提示运行 Unity batchmode/Editor Refresh；涉及客户端结构变更后使用 Unity 2021.3.26f1c1 batchmode 刷新并验证。

---

## [已解决] Logic/View Controller 重构后 Unity csproj 需刷新

第二次重构新增了 `Logic/Controllers/`（8 个文件）、`Logic/NetClient.cs`、`Logic/Context.cs`、`Logic/Data/MapData.cs`、`Logic/Handlers/MapHandlers.cs`，并删除了 `View/Network/NetClient.cs`、`View/Core/Context.cs`、`View/Scene/MapData.cs`。

Unity 自动生成的 `Assembly-CSharp.csproj` 曾引用旧路径且不包含新文件。需在 Unity Editor 中 Refresh 重新生成 csproj，否则 `dotnet build game1.sln` 报 CS2001。

**处理结果**：`dotnet build game1.sln` 已通过，说明 csproj 已包含现有文件结构。Robot.csproj 不受影响（通过 Compile Include 自动引用）。
