# 行式知识库

LINEKB:RULE:001 kind=rule scope=all note="知识库是面向 rg 检索、面向 Agent 编写、面向大型项目长期维护的项目记忆，不是文章。"
LINEKB:RULE:002 kind=rule scope=all note="一条知识必须是一整行；不要把一条知识拆成多行，也不要用段落承载知识。"
LINEKB:RULE:003 kind=rule scope=all note="每行前缀必须是稳定标签，格式建议为 LINEKB:领域:语义。"
LINEKB:RULE:004 kind=rule scope=all note="知识库核心是代码指向和检索入口，优先写 path=、symbol=、scene=、config=、test=、doc= 等可定位字段。"
LINEKB:RULE:005 kind=rule scope=all note="知识库是辅助导航层，不是权威数据；代码、Unity 资源、配置、测试和当前保留文档始终是权威来源。"
LINEKB:RULE:006 kind=rule scope=all note="代码探索、结构理解、业务逻辑分析前先在 docs/line-kb/ 中检索相关标签、路径、类名、方法名或配置名，再去权威来源确认。"
LINEKB:RULE:007 kind=rule scope=all note="改代码、Unity 资源、协议、关键 docs、入口、路径、业务不变量、易错流程、别名或跨模块关系后，必须检查是否需要同步 docs/line-kb/。"
LINEKB:RULE:008 kind=rule scope=all note="新增知识使用 Markdown 普通文本行，不使用表格、长列表、连续叙事段落或多行代码块表达知识。"
LINEKB:RULE:009 kind=rule scope=all note="发现知识库和代码、Unity 资源、配置、测试或当前保留文档冲突时，以权威来源为准，并修正对应知识库行。"
