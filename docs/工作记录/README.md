本目录保存已经完成的机制改动、复杂缺陷修复、项目接手结果和重要工程入口。当前缺陷维护在 `docs/缺陷列表.md`，未来计划维护在 `docs/计划任务.md`，待验证事项维护在 `docs/测试列表.md`。

## 维护规则

- 按完成日期写入对应的 `YYYY-MM.md`，月份不存在时创建文件并补充本索引。
- 只记录最终状态，不记录每次尝试和普通参数微调。
- 同一轮相关改动合并为一条；跨月完成时写入最终完成月份。
- 记录实际验证；未执行的验证链接到 `docs/测试列表.md`。
- 已完成任务从缺陷列表或计划任务中移除，不在工作记录中维护“待办状态”。
- 只有存在可复用的真实版本时，才使用“关联版本”附提交号；没有关联版本时省略该字段。
