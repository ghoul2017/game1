# 进入游戏 优化

## 概述
EnterGameHandler 用 UserRole 验证角色归属；Role 合并入 RoleDataComponent 消除冗余；PlayerEntity 创建逻辑迁移到 Player 模块。

## 1. EnterGameHandler 用 UserRole 验证

### 分析
当前 EnterGameHandler 加载完整 Role 实体验证 userId 匹配，但 UserRole 已有 UserId 字段，且是轻量索引，更适合做归属验证。

### 修改文件

### server/Game/Components/User/UserHandler.cs: EnterGameHandler
- 变更类型：修改
- 验证逻辑：`MongoDb.Instance.QueryFirstOrDefaultAsync<UserRole>(r => r.RoleId == req.RoleId && r.UserId == session.UserId)`
- 不再加载 Role 实体
- 创建 PlayerEntity 交给 PlayerSystem（见第3点）

## 2. Role 合并入 RoleDataComponent

### 分析
当前 RoleDataComponent 只有一个 `Role? Role` 字段，纯粹是 Role 的包装。合并后 RoleDataComponent 直接持有所有角色持久化字段，实现 IEntity，遵循项目 Component + IEntity 持久化模式。

### 修改文件

### server/Game/Components/Player/RoleDataComponent.cs
- 变更类型：重写
- 实现 IEntity，添加 `[BsonId] public long Id { get; set; }`
- 将 Role 的所有持久化字段搬入：UserId, Name, Level, Job, Exp, VipLevel, LastLogoutTime, CreateTime
- 运行时字段 `[BsonIgnore] public string LastToken { get; set; } = "";`
- 删除 `Role? Role` 引用

### server/Game/Components/Player/Role.cs
- 变更类型：删除

### server/Game/Components/Player/PlayerEntity.cs
- 变更类型：修改
- `Create()` 方法：不再接收 Role 参数，改为只接收 roleId + userId
- `Create()` 中 AddComponent<RoleDataComponent> 时不设 Role 字段

### server/Game/Components/Player/PlayerSystem.cs
- 变更类型：修改
- `LoadRoleAsync()` → `LoadRoleDataAsync()`：加载 RoleDataComponent（从 role 集合，需确认集合名映射）
- `SaveRoleAsync()`：保存 RoleDataComponent

### server/Game/Components/Player/PlayerHandlers.cs
- 变更类型：修改
- OnPlayerOnline：加载 RoleDataComponent 而非 RoleAttributeComponent 中关联的 Role

### 其他引用 Role 的文件
- 需批量替换 `player.RoleData.Role.XXX` → `player.RoleData.XXX`
- 需确认所有 Role 引用迁移完毕

## 3. PlayerEntity 创建逻辑迁移到 Player 模块

### 修改文件

### server/Game/Components/Player/PlayerSystem.cs
- 变更类型：新增方法
- 新增 `EnterGame(this PlayerComponent self, long roleId, long userId, TcpSession session)` 方法：
  - 创建 PlayerEntity
  - 加载 RoleDataComponent
  - 绑定 session
  - 生成 Token
  - AddPlayer
  - 发布 PlayerOnlineEvent
  - 返回 (PlayerEntity, string token)

### server/Game/Components/User/UserHandler.cs: EnterGameHandler
- 变更类型：修改
- 精简为：验证 UserRole → 调用 `Context.Players.EnterGame(roleId, userId, session)` → 填充响应

## 数据库变更

- 集合 `role` 不变，文档结构从 Role 迁移到 RoleDataComponent（字段名完全一致，BSON 兼容）
- 集合 `user_role` 不变

## 执行顺序

1. RoleDataComponent 重写（合并 Role 字段 + IEntity）
2. PlayerEntity.Create() 修改（去掉 Role 参数）
3. PlayerSystem 新增 EnterGame() 方法
4. PlayerSystem LoadRoleDataAsync/SaveRoleAsync 修改
5. 批量替换所有 Role 引用
6. EnterGameHandler 精简（UserRole 验证 + 调用 PlayerSystem.EnterGame）
7. 删除 Role.cs
8. 编译验证
